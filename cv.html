What I'm capable of grounded in shipped work

Onchain settlement
Native-ETH settlement with one signed transaction per action: quote → sign in wallet → verify the transfer by hash → run the action → refund on failure. A double-entry ledger for points and ETH where every test ends with a conservation check that sums to zero. USD-priced markets settled in ETH from a WETH/USDG pool price. x402 USDC payments for AI tools.
Launchpads & liquidity
Six launch models, implemented and documented: Raydium LaunchLab bonding curves to CPMM, Orca Whirlpools with the whole supply in one permanently locked position (no custom program), Meteora Dynamic Bonding Curve to DAMM v2, Doppler multicurve on Uniswap v4, own Solidity bonding curves graduating into locked Uniswap v3 pools, and LayerZero OFT launches across five chains at one USD price.
Fee flywheels
Buyback-and-burn with capped price impact, holder-reward rounds with anti-sybil snapshots, creator trust bonds with cliffs and linear vesting, and a 10% tax token whose treasury parks USDG in a Morpho vault and spends only the yield on guarded buybacks.
AI agents in production
Agents that hold wallets and act: a per-coin agent that posts on X, trades its coin, builds the coin's website and spends creator fees on buybacks; an autonomous Meteora DLMM LP agent on a ReAct loop with a structured decision log; chat-trading agents with custodial wallets where spend limits, confirm codes and TWAP price guards live in plain code the model cannot touch.
Trading UX
In-site swaps with quotes, USD values, price impact and route before signing; Jupiter on Solana, Uniswap v4 with Permit2 on Robinhood Chain. Candles, holders, top traders, average-cost P&L, leaderboards, watchlists, and wallet-signed callouts (EIP-712 on EVM, signed messages on Solana).
Game & economy design
A full card-game economy: packs, level-ups, fusion, salvage, a market with escrow bids and expiry, seasonal Ranked ladders, a live-or-bot Arena queue, server-side turn-based fights, clans, and an oracle that scores real X engagement into card power. Economy notes and a published player book.
Ops & security
Hardened VPS (ufw, fail2ban, sshd, sysctl), Caddy, systemd units and timers, scheduled backups, Cloudflare tunnels. Per-IP rate limits with escalating autobans and attack-path probes, password-gated pre-launch sites, admin panels where every route is walked without a session and must answer 401, internal contract audits and Foundry fork tests.
How I work
Specs first, then a fleet of coding agents builds, reviews and deploys while I direct and curate. Every repo ships with an agent skill and a CLAUDE.md so the next build starts from proven code. Solo delivery of what usually takes a small team.

Social Arena

preview private repo Sep – Oct 2026

founder · game + economy + chain · Robinhood Chain · 266 commits

  • Separate admin panel, player book, hardened VPS with Caddy, systemd timers and backups.

rocapad

preview private repo Oct 2026

founder · SDK + keeper + indexer + web + bot · Solana

A Solana memecoin launchpad built on Orca with no program of its own. Each coin launches straight into an Orca Whirlpool that holds the whole supply in one permanently locked position, so it trades from the first block and creators earn from every trade.

  • TypeScript SDK: launch transactions, pool quotes and swaps, fee collection and split, holder-reward allocation, launch validation, account decoders.
  • Keeper that collects every locked position's fees and pays each coin's fee mode (creator, buyback-and-burn, holder rewards) with a ledger memo on every transaction.
  • Postgres indexer and JSON API: lists with 24h change, charts, trades, milestones, fee ledger, creator earnings, holders, platform stats.
  • Next.js app with a live market terminal, creator dashboard and admin; a grammY Telegram bot with custodial wallets and pool trading.

Smoke Signal

preview private repo Oct 2026

founder · scanner + site · Robinhood Chain

Scores every new token on the Torch launchpad within seconds. It reads the fee split, the creator's record and the buy flow, and shows the result on a fast ASCII-dot site with tiers gated by the $SIGNAL balance.

  • One Node process with built-in SQLite, about 100 MB of RAM; plain HTML, CSS and JS modules with no build step.
  • WebGL2 ASCII dot field, server-sent events for live signals, Telegram channel posting, wallet sign-in with viem.
  • Scanner backs off when the upstream is busy; systemd unit and Cloudflare tunnel for deploy.

Karin

preview private repo Oct 2026

token site + swap + admin · Solidity + web · Robinhood Chain

A tax-to-yield-to-buyback token. Each buy and sell of $KARIN pays a 10% tax in ETH. The treasury converts it to USDG, supplies the Steakhouse USDG vault on Morpho, and spends only the vault yield on buybacks, which pay the tax again.

  • Landing page, swap panel and admin dashboard; admin controls the contract address, trade panel and site gate at runtime.
  • Password-gated pre-launch site enforced on the server, with Vercel middleware parity.
  • Per-IP rate limits, escalating autobans (1h, 24h, 7d), attack-path probes, bans that survive restarts.
  • Live test that simulates a buy and a sell on mainnet without sending transactions.

Altnero

chat agent + launchpad · contracts, agent service, web · Robinhood Chain

Two products in one monorepo: a Bankr-style chat-trading agent and a pump.fun-style launchpad. Meridian

autonomous LP agent · Solana · Meteora DLMM
