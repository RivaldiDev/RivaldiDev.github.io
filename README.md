# rivaldi.dev — portfolio v2.0

> **Vibecoder · Full AI Agentic · Web3 Enthusiast**

Live at **[rivaldidev.github.io](https://rivaldidev.github.io)** — built with zero frameworks, zero build steps, zero dependencies. Just modern web platform + GitHub Pages.

## ✨ Features

- **Neural network canvas** — mouse-reactive particle background
- **Live GitHub API integration** — the projects grid renders itself from `api.github.com` on every page load. Push a new repo → it appears on the site. Zero maintenance.
- **Interactive terminal** — a real shell visitors can type into (`help`, `whoami`, `gm`, …)
- **Command palette** — `Ctrl+K`, like a proper dev tool
- **Agent boot sequence** — typed out character-by-character in the hero terminal
- **Modern CSS** — `color-mix()`, glassmorphism, scroll-driven animations (progressive enhancement), `text-wrap: balance`, custom 404 page
- **Accessible** — respects `prefers-reduced-motion`, semantic HTML, keyboard navigable

## 🧱 Stack

| Layer | Choice |
|---|---|
| Framework | none — the platform is the framework |
| Build step | none — push = deploy |
| Hosting | GitHub Pages |
| Data | GitHub REST API (client-side) |
| Fonts | Space Grotesk + JetBrains Mono |

## 🚀 Deploy

```bash
git push origin main   # that's it. that's the pipeline.
```
